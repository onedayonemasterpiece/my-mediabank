# My MediaBank

Минимальный Android-прототип для проверки того, как Мира Live видит фотографии и оценивает их открыточность. Чёрный экран, одна фотография, голос, балл от 1 до 10. Фотографии идут от новых к старым.

## Первая версия

- Android читает доступные фотографии через MediaStore; оригиналы не изменяет.
- Один JPEG-просмотр до 2048 px / 2 МиБ передаётся по авторизованному WSS.
- Python-бэкенд исправляет EXIF-ориентацию, уменьшает фото до 1024 px / 180 КиБ и передаёт Мире через `live-interaction`.
- Мира описывает видимое, вызывает маленький инструмент структурированной оценки и озвучивает результат. Оценка сопровождается причиной.
- Голос, VAD, воспроизведение, WSS, переподключение и сжатие контекста — общий `live-interaction` 0.3.27. Собственного голосового движка нет.
- Доступ к модели — только через приватный `ai-resource-control`, consumer `my-mediabank`. Другая модель для оценки не подключается, чужой fallback-ключ не используется.
- В приложении видны подключение, ожидание, речь, отключение и ошибка. Оценка предыдущего кадра не может быть применена к следующему.

Публикация, Telegram-архив, видео, геопоиск и удаление оригиналов в MVP отсутствуют. Никакая оценка не удаляет фотографию. Это проверка качества суждений Live, а не проверенный прогноз аудитории.

## Запуск на сервере

Python 3.11+, Node 22+, версия общего Live-пакета из `vendor/` и отдельно установленный приватный SDK ресурсного контроллера. `scripts/build-web.mjs` проверяет версию и SHA-256 архива, затем генерирует браузерные assets. Сгенерированный голосовой код не редактируется и не коммитится.

```sh
python -m venv .venv
.venv/bin/pip install vendor/live-interaction-0.3.27-py.tar.gz
.venv/bin/pip install -e '.[test]'
# Install the private ai-resource-control SDK through the existing trusted deployment.
npm ci
npm run build
.venv/bin/python -m unittest discover -s tests -v
```

Перед Live-сессией отдельный consumer `my-mediabank` должен быть зарегистрирован в существующем контроллере. Секреты остаются в серверном `EnvironmentFile`, не в APK, репозитории или браузере. Обязательные имена параметров: `MY_MEDIABANK_ORIGIN`, `MY_MEDIABANK_STATE_DIR`, `MY_MEDIABANK_STATIC_DIR`, `AI_RESOURCE_CONTROL_URL`, `AI_RESOURCE_CONTROL_SERVICE_KEY`. Рекомендуемый unit в `deploy/` слушает loopback и требует HTTPS/WSS reverse proxy.

Локальная команда `.venv/bin/my-mediabank-admin invite` создаёт одноразовый код владельца. Код вводится один раз в приложении; дальше используется собственная HttpOnly/Secure сессия. Публичного метода выдачи кодов нет.

## Что хранится

SQLite содержит только хеши приглашений/сессий и короткие счётчики входа. Фото, звук и истории туда не пишутся. В памяти бэкенда — максимум четыре уменьшенных просмотра, не больше двух на сеанс входа, с TTL 15 минут. Активная Live-сессия держит только текущий кадр и текущий результат. После остановки память освобождается; журнал модели ограничивается общим фреймворком.

## Сборка Android

JDK 17, Android SDK 35, Gradle 8.10.2. См. `android/README.md` для параметров подписи и URL. APK содержит только адрес сервера. Первая установка и системные разрешения выполняются пользователем. Голос использует тот же браузерный клиент, что Projects Hub.

## Как проверить гипотезу

Просмотреть несколько разных серий: удачные кадры, обычные снимки и явный брак. Сравнить описание с тем, что действительно на фото; сравнить оценки между собой. Особенно полезно проверить, не получает ли всё подряд 8–9, различает ли Мира выразительность и просто узнаваемый сюжет, учитывает ли свет/композицию. Уменьшенный просмотр не доказывает техническое качество полноразмерного оригинала.

При смене фото во время незаконченного ответа текущий голосовой ответ останавливается, затем включается текущий кадр. При обычном переходе после ответа остаётся та же Live-сессия. После потери связи старая речь не воспроизводится повторно.
